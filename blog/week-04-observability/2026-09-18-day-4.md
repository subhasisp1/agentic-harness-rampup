# Week 4, Day 4 (Fri):

## Goal
Today we emit the same spans as OpenTelemetry, and get the measuring into the assistant I actually talk.


## Concepts, in plain words :
- OpenTelemetry is the vendor-neutral standard for traces. It is not a product and it has no
  screen of its own: it defines the span format and ships the spans to whatever backend you
  point it at, Jaeger, Grafana Tempo, Datadog. The console exporter just prints them.
  
- The export is a replay, because the tracer already had the standard's shape.
  `start_span(name, context=parent, start_time=ns)` and `span.end(end_time=ns)` take explicit
  parents and timestamps, so the exported trace matches the tree exactly.

- LangSmith would have been two environment variables and no lesson. Writing the tracer first
  made the standard readable instead of magic, which was the point of starting by hand.

## The CLI gets a cost meter :
`--trace` attaches a tracer to every turn, prints one line after each answer, appends the run to
`traces.sqlite`, and prints a session total on the way out. `--tree` prints the tree as well.
With neither flag the chat behaves exactly as it did in week 3, so measuring is opt-in.

```
> what headroom did I have?
2 GB of headroom.
[read_notes | 1200 in + 75 out | $0.001575 | 0.4 s]
```
