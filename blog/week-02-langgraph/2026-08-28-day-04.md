Till now, we have been using `InMemorysaver()'. Kill the process and the conversation is gone. Today the checkpointer becomes a

# SQLITE SAVER :

`SqliteSaver` ( package `langgraph-checkpoint-sqlite` ) as a alternative of `InMemorySaver`, backed by a sqlite3 file. The swap is the one argument
passed to `build_graph`. `SqliteSaver.from_conn_string(path)` is a context manager,it opens the connection and closes it at the end of the `with`
block, and the tables get created on first use.

```python
with SqliteSaver.from_conn_string(str(DB)) as saver:
    toolbelt = build_graph(saver)
    saved = toolbelt.get_state(config)
    on_record = len(saved.values.get("messages", []))
    print(f"Toolbelt, thread '{args.thread}': {on_record} messages on record.")
```

Now the tabs ( here 'thread_id ) survive after closing the browser, re-running the script,etc. `--thread work` and `--thread play` are two independent
histories in one file, and a thread that does not exist yet has `get_state(config).values == {}`, which is where "0 messages on record" comes from.
`--budget` sets the tool-call budget per turn ( default 3 ) ; the router resets the counter every turn.

# THE PAUSED RUN :

Yesterday's caveat became today's work. If the process dies in the middle of an approval ( Ctrl-C at the y/n prompt ), the checkpoint on disk has
`next == ('tools',)` and the pending question in `get_state(config).tasks[0].interrupts`. Sending new input at that point starts a new run and leaves a
tool call without a result, and the API rejects such a history on the next call. So on startup the CLI checks `saved.next` : if a run is paused, it
asks the pending approval first and resumes with `Command(resume=...)`, or with `invoke(None, config)` if the pause was not an interrupt. Only then it
reads new input.


# TAKEAWAYS :
- Memory across restarts was a one-argument change. Making the CLI correct around it ( the paused run ) was the real work.
- A thread is a conversation, a checkpoint is a moment in it, and an interrupt is a checkpoint that waits for a person.
