Todays work will reflect on the improvmenets of yesterday's takeaways and caveats found.We cant blidnly trust 
the output from llm, and have to pass it through a schema:using structutred output which is a validation object.
You create the class, define the schema , and pass it to the model like "llm = get_llm().with_structured_output({Schema Class})".
So now when you invoke the llm , it will give the output according to the defined schema. 

For example : For the code 
```python 
class Acronym(BaseModel):
    acronym: str
    expansion: str
    domain: str
    confidence: float = Field(ge=0, le=1)

llm = get_llm().with_structured_output(Acronym)
out = llm.invoke("What does LCEL stand for?")
```
The output will have all the attributes of Acronym class filled.You can keep a threshold on confidence here to count the answer as correct or not.
