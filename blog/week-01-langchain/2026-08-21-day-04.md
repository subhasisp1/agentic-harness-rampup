# DAY 4 :
Today's goal is to add memory to our agent and wrap it to a small cli.The agent's state is message list, so memory wont be a new component, it is 
just the same state persisted between invokes.In Langcahin we call it as a checkpointer.

In the same create_agent function we can add the checkpointer using InMemorySaver() class.The catch is when you invoke this agent with checkpointer, you need to pass a thread_id 
through a dictionary.Thread_id can be treated as a new chat tab when we use any frontier llm based chat apps. Every invoke with the same `thread_id` loads the saved conversation,
appends the new turn, and saves again.

InMemorySaver lives in process memory : so once we reload/rerun the script/cli, the memory gets deleted. We can use atabase-backed
checkpointer to store the chats , as a solution.
